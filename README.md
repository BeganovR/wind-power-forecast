# Прогнозирование выработки ветропарка

Решение задачи прогнозирования почасовой выработки ветроэнергетической установки (ВЭС) на Q1 2026 года.

## Стек технологий

- **Python 3.10+**
- CatBoost 1.2+ (основная модель)
- XGBoost 2.0+
- scikit-learn (IsotonicRegression, вспомогательные утилиты)
- pandas, numpy, scipy

## Структура репозитория

```
.
├── config.yaml          # Гиперпараметры и пути
├── features.py          # Инженерия признаков
├── train_model.py       # Обучение ансамбля CatBoost (20 мешков)
├── train_xgb.py         # Обучение ансамбля XGBoost (6 мешков)
├── predict_q1.py        # Прогноз Q1 2026
├── predict_xgb.py       # Прогноз Q1 2026 (XGBoost)
├── create_submission.py # Финальный бленд и submission
├── requirements.txt     # Зависимости
└── docs/
    └── model_description.md  # Пояснительная записка
```

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка данных

Разместить файлы датасета:
```
../data_extracted/dataset/train_dataset.csv
../data_extracted/dataset/valid_features.csv
```

Разместить файл с фактическими данными за апрель 2026:
```
../data_extracted/dataset/test_dataset.csv  # апрель-май 2026
```

Обновить пути в `config.yaml` при необходимости.

### 3. Обучение модели

```bash
# Обучение CatBoost (основная модель, ~30 мин)
python train_model.py

# Обучение XGBoost (вспомогательная модель, ~25 мин)
python train_xgb.py
```

### 4. Генерация прогноза

```bash
# Q1 2026
python predict_q1.py

# XGBoost прогноз
python predict_xgb.py

# Финальный бленд
python create_submission.py
```

Результат: `submission_q1_2026.csv` и `submission_may18.csv`

## Описание модели

### Признаки (135 штук)

Инженерия признаков разделена на несколько блоков:

- **Физические**: мощность ветра (r*v^3), профиль скорости по высотам, нормированная плотность воздуха
- **Ветровой вир**: угловые разности направления ветра между высотами 10/80/120/180 м - прокси турбулентности и атмосферной нестабильности
- **Обледенение**: риск, тяжесть, накопленные часы обледенения за 4/8/12/24 ч, продолжительность непрерывной серии
- **Временные**: циклические sin/cos часа, месяца, дня года
- **Лаговые**: скорость ветра 80 м за +-1..6 часов, направление за +-1 ч
- **Профиль атмосферы**: вертикальные сдвиги скорости (показатель Хеллмана), изотропное сглаживание power-curve prior через монотонную регрессию
- **Работоспособность**: количество рабочих турбин, нелинейность n_working^2

### Архитектура

Двухуровневый ансамбль:

1. **CatBoost** (20 мешков, seeds 42-61): функция потерь MAE, глубина 9, learning rate 0.020, 1369 итераций. Обучен на train + фактические данные апреля 2026.

2. **XGBoost** (6 мешков, seeds 200-205): objective reg:absoluteerror, глубина 8, 2200 итераций.

**Финальный бленд**: CatBoost 62% + XGBoost 28% + дополнительные модели 10% (оптимизировано по OOF Q1 2025).

### Взвешивание обучающих примеров

- Зима (Q1): бонус x2.5 (целевой сезон)
- Апрель 2026 (фактические данные): бонус x1.8
- Зона 6-12 м/с в Q1: бонус x1.4 (50% ошибки модели)
- Низкая температура (T < 0°C, Q1): бонус x1.5
- Обледенение: бонус x1.5

### Power Curve Prior

Монотонная изотоническая регрессия (vp_80m = r*v^3 -> CF) используется как дополнительный признак - обеспечивает физически корректную форму кривой мощности.

## Результаты

| Модель | Q1 2025 OOF MAE% |
|--------|------------------|
| CatBoost (20 мешков, без veer) | 8.28% |
| CatBoost (20 мешков, с veer)   | **8.22%** |
| Финальный бленд (с XGBoost)    | ~8.18% |

Q1 2025 - аномально сложный период (ws80=6.48 м/с, среднее ремонтов=4.3). Q1 2026 (ws80=6.84 м/с, ремонты=3.3) ближе к условиям 2022-2023 гг., ожидаемая реальная MAE - 7.0-7.5%.
