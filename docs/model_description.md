# Пояснительная записка
## Модель прогнозирования выработки ветропарка

---

### 1. Задача и данные

Задача - почасовое прогнозирование суммарной выработки ветропарка (26 турбин Vestas V150, установленная мощность 3,465 МВт каждая, итого 90,09 МВт) на Q1 2026 года (январь-март, 2126 часов).

**Входные данные**: исторические почасовые измерения за 2021-2025 гг. (~32 434 строк). Признаки: скорость и направление ветра на высотах 10/80/120/180 м, температура воздуха, атмосферное давление, осадки, облачность, порывы ветра, количество турбин в ремонте. Дополнительно использованы фактические данные выработки за апрель 2026 г. (720 строк, n_ремонт=3).

**Метрика**: MAE% = (1/N) * сумма|y_факт - y_прогноз| / 90.09 * 100%.

---

### 2. Инженерия признаков (135 признаков)

**Физика ветра:**
- Плотность воздуха r (из уравнения состояния идеального газа по P, T)
- Мощностный прокси vp = r * v^3 на высотах 80 м, 100 м, 120 м
- Показатель профиля скорости Хеллмана (a = ln(v2/v1) / ln(h2/h1))
- Экстраполированная скорость на высоте хаба через log-log регрессию

**Ветровой вир:**
- Угловые разности направления ветра между высотами: 10-80 м, 80-120 м, 80-180 м
- Абсолютные значения и суммарный вир как прокси турбулентности
- Произведение вира на флаг зоны 6-9 м/с (ключевое взаимодействие)

Высокий вир указывает на атмосферную нестабильность, из-за которой реальная выработка оказывается ниже теоретической кривой мощности.

**Обледенение (критично для Q1):**
- Флаг риска: T < 2°C и осадки одновременно
- Тяжесть: (2 - T) * (снег + ливень)
- Накопленные часы обледенения за 4/8/12/24 ч, длительность серии (ice_streak)
- Время с момента окончания обледенения (оттаивание лопастей длится 1-3 ч)

**Временные паттерны:**
- Циклические sin/cos часа, дня года, месяца
- Флаг ночного времени (20:00-06:00) для учета эффекта низкоуровневного струйного течения

**Лаговые и скользящие признаки:**
- Скорость ветра 80 м за -6...+6 ч относительно текущего момента
- Скользящие средние 3/6/12 ч, максимум за 6 ч, тренд и ускорение

**Power Curve Prior:**
- Монотонная изотоническая регрессия vp_80m -> CF как физически корректная основа прогноза

---

### 3. Архитектура модели

Решение - взвешенный ансамбль нескольких моделей градиентного бустинга.

**CatBoost (вес 62%):**
- 20 мешков (bagging), seeds 42-61
- Параметры: depth=9, learning_rate=0.020, loss_function=MAE
- 1369 итераций, определено через early stopping на Q1 2025
- Взвешивание примеров: x2.5 за Q1, x1.8 за апрель 2026, x2.5 за n_ремонт=3, x1.4 за зону 6-12 м/с

**XGBoost (вес 28%):**
- 6 мешков, seeds 200-205
- Параметры: max_depth=8, learning_rate=0.015, objective=reg:absoluteerror
- 2200 итераций, те же 135 признаков

**Дополнительно (вес 10%):** KNN и Extra Trees, добавляют устойчивость на экстремальных режимах.

Все модели обучены на полном наборе данных (исторические + апрель 2026). Веса бленда подобраны по OOF-качеству на Q1 2025.

---

### 4. Качество модели

| Конфигурация | OOF MAE% (Q1 2025) |
|---|---|
| CatBoost 20 мешков | 8.28% |
| CatBoost + признаки вира | 8.22% |
| Финальный бленд | ~8.18% |

Q1 2025 - аномально сложный год: средняя скорость ветра 6.48 м/с, среднее число ремонтов 4.3. Условия Q1 2026 ближе к норме (6.84 м/с, 3.3 ремонта), что дает ожидаемую реальную MAE в диапазоне 7.0-7.5%.

Основной источник ошибок - зона скоростей 6-9 м/с (49.6% суммарной ошибки, MAE = 11.05 МВт*ч/ч), где кривая мощности наиболее нелинейна.

### 5. Инструкция по запуску

```
# Требования: Python 3.10+, CUDA не требуется
pip install -r requirements.txt

# Шаг 1: Обучение CatBoost (~30 мин на CPU)
python train_model.py

# Шаг 2: Обучение XGBoost (~25 мин на CPU)
python train_xgb.py

# Шаг 3: Прогноз CatBoost (Q1 2026 + 18.05.2026)
python predict_q1.py

# Шаг 4: Прогноз XGBoost
python predict_xgb.py

# Шаг 5: Финальный submission
python create_submission.py
```

Пути к данным задаются в `config.yaml` (train_path, valid_path, extra_path). Прогноз на 18.05.2026 создается автоматически при запуске `predict_q1.py`.
